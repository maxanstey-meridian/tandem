# @tandem/sdk

The TypeScript authoring API for [Tandem](https://github.com/maxanstey-meridian/tandem),
a typed agentic pipeline SDK running on .NET and Microsoft Agent Framework.

See the [TypeScript guide](https://github.com/maxanstey-meridian/tandem/tree/main/typescript)
for requirements, examples, and usage.
