# @maxanstey-meridian/tandem-runtime

The platform loader used internally by
[`@maxanstey-meridian/tandem`](https://github.com/maxanstey-meridian/tandem/tree/main/typescript/packages/sdk).
Applications should install and import `@maxanstey-meridian/tandem` rather than this package
directly.
