# @maxanstey-meridian/tandem-runtime-darwin-arm64

The macOS arm64 Tandem host selected by
[`@maxanstey-meridian/tandem-runtime`](https://github.com/maxanstey-meridian/tandem/tree/main/typescript/packages/runtime).
Applications should install and import `@maxanstey-meridian/tandem` rather than this package
directly.
